# Скриншоты проекта



## Список нужных скриншотов

| Файл | Что захватить |
|------|---------------|
| `01_main_window.png` | Главное окно программы сразу после запуска — все три консоли свободны (зелёные карточки) |
| `02_form_filled.png` | Заполненная форма аренды: данные клиента, выбранная консоль, даты, геймпад, игры, рассчитанная сумма |
| `03_order_created.png` | Заказ создан и отображается в таблице, консоль на OpenGL-виджете стала синей |
| `04_order_active.png` | Статус заказа «Активен», карточка консоли оранжевая |
| `05_opengl_widget.png` | Крупным планом OpenGL-виджет: карточки разных цветов (хотя бы 2 разных статуса одновременно) |
| `06_csv_export.png` | Открытый CSV-файл в текстовом редакторе или Excel с данными нескольких заказов |
| `07_uml_diagram.png` | UML-диаграмма классов (из браузера plantuml.com или VS Code) |
