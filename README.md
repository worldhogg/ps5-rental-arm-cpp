# АРМ специалиста сервиса аренды PlayStation 5

Учебный desktop-проект: автоматизированное рабочее место (АРМ) специалиста сервиса
аренды PS5. Написан на C++17, Qt 6 Widgets, с графической визуализацией на OpenGL.

Скриншоты работы приложения — в папке [`screenshots/`](screenshots/).

---

## Цель работы

Разработать настольное приложение, автоматизирующее работу специалиста пункта проката
игровых консолей PlayStation 5. Программа позволяет вести учёт клиентов, консолей и
заказов, рассчитывать стоимость аренды, формировать договор и управлять жизненным
циклом каждого заказа.

---

## Возможности программы

### Оформление аренды
- Ввод данных клиента: ФИО, номер телефона, номер документа
- Выбор свободной консоли PS5 из трёх доступных
- Выбор дат аренды через встроенный календарь
- Подключение дополнительных геймпадов (0–3 шт., 150 ₽/день)
- Выбор дополнительных игр с чекбоксами (150–200 ₽/день каждая)
- Автоматический расчёт итоговой суммы до создания заказа
- Создание заказа одной кнопкой

### Управление заказами
- Таблица всех заказов с отображением статуса
- Переход по этапам жизненного цикла через отдельные кнопки
- Отмена заказа на любом раннем этапе

### Договор аренды
- Автоматическое формирование договора при создании заказа (номер вида `C-0001`)
- Генерация договора в **PDF-документ** и его открытие из приложения
- Отправка договора администратору
- Отдельный жизненный цикл статусов договора

### Проверка возврата
- Имитация внешнего диагностического бокса (питание, HDMI, геймпад, накопитель, комплектность)
- Фото- и видеофиксация внешнего состояния консоли
- Автоматическое или ручное решение о завершении аренды

### OpenGL-визуализация
- Три карточки консолей с упрощённым силуэтом PS5
- Цвет карточки динамически меняется по статусу
- Подписи: номер консоли и текущий статус
- Автообновление при каждом изменении состояния

### Экспорт данных
- Экспорт журнала заказов в файл CSV (UTF-8)
- Сохранение через системный диалог выбора пути

## Сборка и запуск

### macOS (Homebrew)
```bash
brew install qt cmake
cmake -S . -B build -DCMAKE_PREFIX_PATH=$(brew --prefix qt)
cmake --build build
./build/ps5-rental-arm-cpp
```

### Ubuntu / Debian
```bash
sudo apt install qt6-base-dev libqt6opengl6-dev cmake build-essential
cmake -S . -B build
cmake --build build --parallel
./build/ps5-rental-arm-cpp
```

## Описание основных классов

### `Client`
Хранит персональные данные клиента: ФИО, телефон, номер документа. Геттеры и сеттеры
для каждого поля.

### `ConsoleDevice`
Игровая консоль PS5: идентификатор, название, цена в сутки, статус (`ConsoleStatus`).
Управляет переходами статуса при создании и завершении аренды.

### `Game`
Игра для дополнительной аренды: идентификатор, название, цена в сутки.

### `RentalOrder`
Центральный класс. Хранит снимок клиента, снимок консоли, даты аренды, число геймпадов,
список игр и статус (`RentalStatus`). Метод расчёта стоимости `getTotalPrice()`.

### `RentalManager`
Уровень бизнес-логики. Агрегирует коллекции консолей, игр и заказов. Создание заказа,
переходы по статусам, расчёт стоимости, экспорт в CSV, инициализация тестовых данных.

### `RentalContract`
Договор аренды: номер (`C-0001`) и статус договора (`Подписан` / `Активен` / `Закрыт` /
`Ручная проверка`). Ведёт свой жизненный цикл параллельно заказу.

### `ContractPdfGenerator`
Формирует договор аренды в виде PDF-документа для открытия и отправки администратору.

### `ReturnBoxSimulator`
Имитация внешнего диагностического устройства: проверка питания, HDMI, геймпада,
накопителя и комплектности. Возвращает результат по каждому пункту.

### `ReturnCheckResult`
Хранит результат технической проверки возврата (статус по каждому пункту: `OK` / ошибка).

### `ReturnMediaRecord`
Запись фото/видеофиксации возврата: пути к файлам, выбранное внешнее состояние,
комментарий администратора.

### `ConsoleOpenGLWidget`
Наследует `QOpenGLWidget`. Отрисовка трёх карточек консолей: силуэт PS5, LED-линия,
подписи, цветовая индикация статуса.

### `MainWindow`
Главное окно. Строит весь UI программно (без `.ui`-файлов), связывает кнопки со слотами,
обновляет таблицу заказов и OpenGL-виджет.

## OpenGL-визуализация

Блок «Статус консолей» в правой части окна. Через OpenGL рисуются три карточки — по одной
на консоль.

**На каждой карточке:** фон по статусу, упрощённый силуэт PS5 (корпус, тёмная полоса,
синяя LED-линия, ножки), надпись `PS5 #N` сверху и статус снизу.

**Цвета по статусу:**

| Цвет      | Статус консоли    |
| --------- | ----------------- |
| Зелёный   | Свободна          |
| Синий     | Забронирована     |
| Оранжевый | В аренде          |
| Красный   | Проверка возврата |
| Серый     | Недоступна        |

Визуализация обновляется автоматически при любом изменении статуса.

## Жизненный цикл заказа

```
Создан → Активен → Проверка возврата → Завершён
    ↘         ↘
    Отменён   Отменён
```

| Статус        | Описание                                   | Кнопка перехода       |
| ------------- | ------------------------------------------ | --------------------- |
| `Created`     | Заказ создан, консоль забронирована        | — (автоматически)     |
| `Active`      | Консоль выдана клиенту                      | **Начать аренду**     |
| `CheckReturn` | Клиент вернул консоль, ожидает проверки     | **Проверка возврата** |
| `Completed`   | Аренда завершена, консоль свободна          | **Завершить**         |
| `Canceled`    | Заказ отменён, консоль освобождена          | **Отменить заказ**    |

## Расчёт стоимости аренды

```
Итого = (цена_консоли + кол_геймпадов × 150 + сумма_цен_игр) × кол_дней
```

- Цена консоли: 800 ₽/день (задаётся в коде при инициализации)
- Дополнительный геймпад: 150 ₽/день
- Игры: 150–200 ₽/день в зависимости от названия

Пример: PS5 Digital #1 (800 ₽) + 1 геймпад (150 ₽) × 1 день = **950 ₽**.

## Договор и проверка возврата

При создании заказа формируется договор (`C-0001`). Его можно **сгенерировать в PDF**,
открыть и отправить администратору. Статусы договора: `Подписан` → `Активен` → `Закрыт`;
при проблемах на возврате — `Ручная проверка` (не закрывается автоматически).

После нажатия **«Проверка возврата»** открывается блок диагностики:
- **Автоматическая проверка бокса** (`ReturnBoxSimulator`): питание, HDMI, геймпад,
  накопитель, комплектность → результат `OK` / `ОШИБКА` по каждому пункту.
- **Фото/видеофиксация** (`ReturnMediaRecord`): добавление фото и видео, выбор внешнего
  состояния, комментарий администратора.

> В учебном проекте проверки бокса возвращают `OK`. В реальной системе методы
> `ReturnBoxSimulator` получали бы данные от физического устройства через USB-HID или
> последовательный порт.

**Кнопка «Завершить»** проверяет три условия: проверка бокса пройдена, осмотр сохранён,
внешнее состояние не `Требуется ручная проверка`. Если всё ок — заказ `Завершён`, консоль
`Свободна`, договор `Закрыт`. Иначе заказ уходит на ручную проверку.

## Экспорт в CSV

- Кнопка **«Экспорт в CSV»** под таблицей заказов, диалог выбора пути
- Кодировка UTF-8, разделитель — точка с запятой (`;`)
- Поля: ID заказа, Клиент, Телефон, Консоль, Дата начала, Дата окончания, Сумма, Статус,
  Номер договора, Статус договора

## Как пользоваться программой

1. Заполните данные клиента — ФИО, телефон, документ
2. Выберите свободную консоль
3. Укажите даты аренды
4. Выберите геймпады и игры
5. **«Рассчитать стоимость»** — увидите итоговую сумму
6. **«Создать аренду»** — заказ появится в таблице
7. **«Сгенерировать договор»** — при необходимости откройте PDF / отправьте администратору
8. Управляйте статусом заказа кнопками; на возврате пройдите проверку бокса и осмотр
9. **«Экспорт в CSV»** — выгрузка журнала заказов
